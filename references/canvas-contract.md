# 画布交互定稿

以下是 2026-11-17 最终确认的设计。旧要求发生冲突时以本文件为准；以后用户的新决定再覆盖这里。模板已实现的功能以实际代码和验证结果为准，不能把设想写成已完成。

## 原件与画布

- 有边界的横向稿纸，磨砂、浅灰、中性的手写草稿质感。不是大面积偏绿背景。
- 中央为竖向 A5 比例原件（148×210）置于横向 A3 参考空间（420×297）。允许放大阅读，不改变原件内容。多篇**翻页**，一篇一面，不纵向堆三篇。
- 中文对照在英文**紧邻右侧**。两张原件边缘贴合无缝，不能放在远处。中文只能来自已保存的对应稿或明确标识的新翻译。
- 不在原图上加标题、引导语、卡片或重新排版的正文。纸外操作默认是少量图标，解释放 tooltip。
- 默认打开缩放 80%，按保存的 openingCenter 恢复视觉位置。临时缩放不覆盖默认打开缩放。

## 定位与聊天

1. 原图有可解析文字时，可以选字、划线，保存精确 UTF-16 范围；无文字层时允许粗略圈画、括号式字头字尾定位或注意点，并保留区域与原图。
2. 默认“加点点”：普通点、花、星、花瓣按规律循环；长拖按固定像素距离布点。颜色轮换，用来引导注意，不等于删文或批准某个改法。
3. 笔迹松手后**原样停留**。不会立即自动变为整齐圈框。用户点复制／引用只保存定位，仍不整理。
4. 用户在聊天解释以后，核对所指原句，将同一 ID 转成 annotation，辅助笔迹淡出，生成较方、带手绘感、贴文字的圈线。圈选不能跨进邻段或整块空白。
5. 英文与中文独立计算圈选范围，共同连到同一条旁批。原句、双语对应、页／段位置、完整 ID、源版本一起保存。
6. 圈和两条引线默认淡显（约 0.2），鼠标悬停本条批注增强（约 0.88），离开恢复。可隐藏引线来减少交叉。

## 旁批输入、排布与编辑

- 留白双击直接出现普通文字编辑状态，像 PPT 输入文字；不弹一套表单，不加独立语音按钮。用户通过当前聊天／系统听写口述。
- 旁批文字较小，接近原件显示字号。行距约 1.18，文字与边框内边距约 **2px**；不做厚卡片、大行距或大块底色。
- 旁批用细柔红边框。按指派顺序从左上角开始**顺时针排两圈，外圈先满，再内圈**。已有手动位置优先，不因刷新重排。
- 单击选中旁批，显示上、下、左、右短线端点手柄；拖边框移动，拖手柄改宽高。变窄自动换行，全部文字必须保留；不能靠剪裁隐藏正文来缩框。
- 不显示六点抓手或冗余三按钮头部。右上角只有极小短 ID；完整 ID 在单条复制中附带。
- 行末是灯泡＋加号，用来展开／收起颜色，旁边是单条复制。它紧接最后文字，不能换到下方自成大工具条。
- 颜色有五个圆形预设＋圆形自选取色入口。选完即收起；最小化后文字更小，仍能查看和展开。旧版 proof 结束方块被灯泡＋加号替代。
- 垃圾桶很小，在框的右上角，与复制按钮保持距离，避免误点。

## 避让、等宽预览与松手

- 移动的框避开其他框，只需约 **0.5px** 间隔；不大幅推走其他批注。
- 拖到另一框内停留 **650ms**，出现半透明虚线的等宽预览。预览使用目标宽度，按本框完整文字计算高度，放在旁边。
- 松手才确认宽度；移开、取消或快速经过不改变宽度。不要刚接触就跳位。
- 全局只允许一个 activeFrameGesture。pointerup、mouseup、lostpointercapture、blur、页面隐藏、pointermove.buttons===0 都要正确结束手势。pointercancel 回滚。
- 结束时先清理手势、pointer capture、吸附计时器、预览和 CSS 状态，再保存／渲染。连线每动画帧最多重画一次。不能松手后仍拖着走。
- 修复卡住状态前，先保存 DOM 中用户刚移动到的位置，不能一刷新就丢位置。

## 固定工具岛

- 底部正中悬浮，**不随稿纸缩放而放大**，视觉中心以工具岛本体计算，不把旁边复制按钮算入中心。
- 上一页、下一页、工具包加号、复制全部在同一紧凑体系。复制全部靠近岛，不在画布远处或右侧常驻工具栏。
- 加号右侧向下展开约 **98×100px** 的圆角迷你调色盘，4 列 20px 图标；常驻可选工具，点工具或画布不自动收起。加号或 Escape 收起，开关状态保存。
- 配色参考 Gemini 的白色、深灰线性图标、淡蓝选中态、轻阴影。图标、点击区、悬停底色严格同心。
- 名称只在悬停约 650ms 后出现，以约 9px 小提示显示；不常显说明。
- 图标用 flex 的 align-items:center 和 justify-content:center，避免 grid 继承样式让视觉中心偏移。

## 撤销、删除与最近删除

- Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做；画布记录最近 20 个快照。编辑文字时保留输入框原生撤销，不劫持文字快捷键。
- 橡皮擦点击可擦一条，长拖形成连续横扫区域，整次拖动只算一步撤销。
- 最近删除只留 **2 条**，固定左下角、像简洁待办列表。第三条删除时淘汰最旧记录。
- 点击最近删除条目，只在原位置展示淡虚影，不立即恢复。独立回退按钮才恢复；坐标与源版本一并保存。

## 明确没有承诺的能力

- 没有宿主桥接时不能把 ID 自动变成聊天附件；提供单条／全部复制作为可靠替代。
- 画布网页无权缩放或改变桌面 Codex／ChatGPT 浮窗透明度。不能用 CSS 假装控制宿主窗口。
- 图片中文字不因有透明定位层而变成可直接编辑的正文。可编辑导出主要编辑旁批、圈线和位置。
